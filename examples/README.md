# Safin-1 examples

- `march/cpt.jsonl`: tiny text fixture for the CPT smoke command.
- `march/sft.jsonl`: tiny conversation fixture for the SFT smoke command.

Use the commands in the [quick start](../docs/march/quickstart.md).
These fixtures check the pipeline; they are not training datasets for the
published models. Other upstream model, RL and multimodal examples are omitted.
