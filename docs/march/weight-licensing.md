# Model-weight licensing

The maintainer selected **Apache-2.0** for all four model weights on 2026-10-17.
Each prepared HF model root contains LICENSE and a model-specific NOTICE.
The upstream Qwen license text, including its Alibaba Cloud copyright, is kept
byte-for-byte in [model-licenses/Qwen3.5-Apache-2.0.txt](model-licenses/Qwen3.5-Apache-2.0.txt).

The [evidence record](weight-licensing-20261017.json) pins the official Qwen and
SFT data-card revisions observed during this review. They are observation pins,
not evidence of the exact upstream versions used during training.

The repository code, derivative weights and training datasets have distinct
license scopes. This license selection does not settle the unresolved CPT data
provenance or replace the training-data review. See [training-data.md](training-data.md).
Public upload remains separate from local preparation.
